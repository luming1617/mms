# 用户面接口总览

> 用户面面向 agent 主服务（API key 鉴权）。所有响应统一包裹 `BaseResp<T>`（`code/message/data`，见[《1.1-用户面-接口鉴权与响应》](1.1-用户面-接口鉴权与响应.md)），下文响应体均指 `data` 结构；失败时 `data=null`。写接口必带 `Idempotency-Key`；`customer_id` 经 `X-Customer-Id` 头传入。标注 **【新定义】** 的字段为本文首次约定，源文档未定义。

| 方法 | 路径 | 用途 | scope |
|---|---|---|---|
| `POST` | `/memories/query` | 语义 + 词法 + 业务过滤检索 | `memory:read` |
| `POST` | `/memories/candidates` | 接收已授权候选（同步决策） | `memory:write` |
| `POST` | `/ingestions` | 创建异步摄取任务 | `memory:write` |
| `GET` | `/ingestions/{job_id}` | 查询摄取任务状态 | `memory:read` |
| `GET` | `/customers/{customer_id}/memories` | 客户记忆摘要（分页） | `memory:read` + 客户范围校验 |
| `POST` | `/memories/{memory_id}/feedback` | 记录反馈 | `memory:feedback` |
| `POST` | `/memories/{memory_id}/corrections` | 提交修正建议 | `memory:write` |
| `POST` | `/deletion-requests` | 请求删除记忆 | `memory:delete` |
| `GET` | `/deletion-requests/{request_id}` | 删除状态/证明 | `memory:delete` |
| `GET` | `/review-queue` | 待审列表（分页） | `memory:review` |
| `POST` | `/review-queue/{review_id}/decision` | 审核决策 | `memory:review` |

# POST /memories/query

在线检索：语义 + 可选词法召回，purpose 驱动状态集与视图选择。

## 请求体

```json
{
  "query": "这个客户之前遇到过哪些登录问题？",
  "conversation_id": "conv_501",
  "purpose": "CURRENT_ANSWER",
  "language": "zh-CN",
  "max_items": 8,
  "max_tokens": 1200,
  "include_types": ["CUSTOMER_PROFILE", "SERVICE_HISTORY", "ACTIVE_ISSUE"],
  "as_of": null,
  "trace_id": "4bf92f..."
}
```

| 字段 | 类型 | 必填 | 含义与取值 |
|---|---|---|---|
| `query` | string | 是 | 检索文本 |
| `conversation_id` | string | 否 | 会话关联 ID，用于 usage 归因 |
| `purpose` | enum | 是 | `CURRENT_ANSWER` / `CUSTOMER_SELF_SERVICE` / `HISTORY_DEBUG` / `AUDIT`；`CANDIDATE_DISCOVERY` 仅限内部；`status_set` 服务端强制映射（12.6/12.9） |
| `language` | string | 否 | BCP-47 查询/词法提示；服务端仍做语言检测，不改变记忆原文语言；视图按 9.3 自动选择 |
| `max_items` | int | 否 | 返回条数上限，默认 8【新定义】 |
| `max_tokens` | int | 否 | 记忆上下文 token 预算（不只是条数），默认 1200，服务端强制执行【新定义】 |
| `include_types` | enum[] | 否 | `CUSTOMER_PROFILE` / `SERVICE_HISTORY` / `ACTIVE_ISSUE` / `COMMITMENT` / `EPHEMERAL_CONTEXT` / `ACCOUNT_FACT`；缺省不限 |
| `as_of` | datetime | 否 | 仅 `HISTORY_DEBUG`/`AUDIT` 可用，需更高权限 |
| `trace_id` | string | 否 | 调用方 trace 关联 |

## 响应体

```json
{
  "memories": [
    {
      "memory_id": "mms_mem_456",
      "memory_type": "SERVICE_HISTORY",
      "content": "客户曾在 Android 客户端登录时遇到验证码超时；已尝试重启应用。",
      "content_language": "zh-CN",
      "language": "zh-CN",
      "matched_view_kind": "ORIGINAL",
      "matched_view_language": "zh-CN",
      "valid_at": "2026-10-20T10:00:00Z",
      "expires_at": "2027-01-18T00:00:00Z",
      "confidence_label": "verified",
      "source_summary": "ticket:T-1234",
      "use_policy": "fact"
    }
  ],
  "requires_confirmation": false,
  "consent_denied": false,
  "consent_unavailable": false,
  "degraded": false,
  "degraded_reason": null,
  "semantic_index_pending": false,
  "lexical_used": false,
  "lexical_mode": null,
  "lexical_skip_reason": "language_not_configured",
  "filtered_reasons": {"expired": 2, "conflicted": 1}
}
```

| 字段 | 类型 | 含义与取值 |
|---|---|---|
| `memories[].memory_id` | string | 记忆 ID |
| `memories[].memory_type` | enum | 同 `include_types` 6 值 |
| `memories[].content` / `content_language` | string | 永远是原文及其语言（BCP-47） |
| `memories[].language` | string | 本次返回的语言 |
| `memories[].matched_view_kind` / `matched_view_language` | enum / string | 命中视图 `ORIGINAL`/`CANONICAL`/`TRANSLATED` 及其语言；不是事实权威 |
| `memories[].valid_at` / `expires_at` | datetime | 生效 / 过期时间 |
| `memories[].confidence_label` | enum | `verified`（权威来源）/ `reported`（用户/坐席陈述）/ `inferred`（模型推断）【新定义】 |
| `memories[].source_summary` | string | 最小化来源摘要（如 `ticket:T-1234`），不泄露未授权内部信息 |
| `memories[].use_policy` | enum | `fact` / `context_only` / `history_only` / `audit_only`，与状态矩阵一一对应 |
| `requires_confirmation` | bool | 是否需向客户确认后再使用 |
| `consent_denied` / `consent_unavailable` | bool | 同意闸结果（见处理流程），命中时 `memories` 为空 |
| `degraded` / `degraded_reason` | bool / string | 依赖降级及原因（embedding 超时 / 词法 / 翻译 / 权威系统不可用） |
| `semantic_index_pending` | bool | 部分新记忆向量未就绪，仅内部诊断 |
| `lexical_used` / `lexical_mode` | bool / enum | 词法是否命中；命中时 `fts` / `trgm`，否则 `null` |
| `lexical_skip_reason` | enum | `language_not_configured` / `tokenizer_unavailable` / `query_too_short` / `index_unavailable`；启用时 `null` |
| `filtered_reasons` | map | 过滤原因→计数（如 `expired`/`conflicted`），只返回计数 |


# POST /memories/candidates

接收投递方已完成提取的单个候选，同步走写入主链（过闸→决策→写入，同事务）。202 为历史契约：处理已同步完成，新客户端不应据其推断"未完成"。

## 请求体

即 CandidateInput（契约以 `contracts/candidate.schema.json` 为准，见《04-记忆抽取》4.7）；`candidate_id/customer_id/source_system/source_event_id/policy_version` 等由服务端注入，不在请求体。

| 字段 | 类型 | 必填 | 含义与取值 |
|---|---|---|---|
| `memory_type` | enum | 是 | `CUSTOMER_PROFILE` / `SERVICE_HISTORY` / `ACTIVE_ISSUE` / `COMMITMENT` / `EPHEMERAL_CONTEXT` / `ACCOUNT_FACT` |
| `fact_key` | string | 是 | 事实键，须在注册表 ACTIVE（见 2.2 `/admin/fact-keys`） |
| `subject` / `predicate` | string | 否 | 主谓结构化描述 |
| `entity_type` / `entity_ref` | string | 否 | 实体类型与引用（如订单号） |
| `value_slot` | string | 否 | 值槽位（多值事实区分） |
| `object_json` | object | 否 | 结构化值（别名 `object`） |
| `content` | string | 是 | 记忆原文，1–4000 字符 |
| `content_language` | string | 是 | 原文语言，BCP-47 |
| `language_confidence` | float | 否 | 语言检测置信度 0–1 |
| `source_kind` | enum | 是 | `SYSTEM_OF_RECORD` / `USER_EXPLICIT` / `AGENT_CONFIRMED` / `USER_IMPLICIT` / `MODEL_INFERRED` / `KNOWLEDGE_RETRIEVED` / `ASSISTANT_GENERATED` |
| `source_refs` | object[] | 是 | 证据定位符，至少一个（如 `{source_event_id}`）；服务端规范化落 `memory_evidence` |
| `confidence` | float | 否 | 提取置信度 0–1，仅参考，不直接决定准入 |
| `sensitivity` | enum | 是 | `LOW` / `MEDIUM` / `HIGH` |
| `explicit_correction` | bool | 否 | 是否显式纠正，默认 false |
| `valid_from` / `valid_to` | datetime | 否 | 事实有效期，`valid_to > valid_from` |
| `observed_at` | datetime | 是 | 事实观察时间 |

幂等：`candidate_fingerprint = SHA-256(canonical_json({source_system, source_event_id, fact_key, entity_type, entity_ref, value_slot, 证据定位}))`，唯一键 `(customer_id, source_system, source_event_id, candidate_fingerprint)`；重复提交返回原决策。

## 响应体（HTTP 202）

决策结果（结构见《07-记忆写入决策》）：

| 字段 | 类型 | 含义与取值 |
|---|---|---|
| `decision_id` / `candidate_id` | string | 决策与候选 ID |
| `outcome` | enum | `ADD` / `ADD_TEMPORAL_VERSION` / `REINFORCE` / `SUPERSEDE` / `NOOP` / `CONFLICT` / `NEEDS_VERIFICATION` / `IGNORE` / `REJECTED` / `DELETE_REQUESTED` |
| `target_memory_id` / `new_memory_id` | string | 被作用 / 新产生的记忆 ID |
| `reason_codes` | string[] | 决策原因码，全集为《07》规则表 R001–R110（如 `MISSING_EVIDENCE` / `CONFLICTING_VALUES` / `SAME_FACT_SAME_VALUE` / `SENSITIVE_DATA`） |
| `policy_version` / `fact_key_registry_version` / `engine_version` | string | 决策钉住的三个版本 |
| `semantic_hash` / `normalization_version` | string | 语义指纹与归一化版本 |
| `requires_review` | bool | 是否进入审核队列 |
| `embedding_action` / `view_actions` / `index_generation` | string / array / int | 向量与视图后续动作、屏障代际 |

# POST /ingestions

创建异步摄取任务：受理过闸 + Job/Inbox 落库即返回，Worker 后台执行提取→决策→写入。

## 请求体【新定义】

| 字段 | 类型 | 必填 | 含义与取值 |
|---|---|---|---|
| `event_id` | UUID | 是 | 投递方事件 ID，幂等去重 |
| `candidate` | object | 是 | CandidateInput，字段同 `/memories/candidates` 请求体 |

## 响应体（HTTP 202）

| 字段 | 类型 | 含义与取值 |
|---|---|---|
| `job_id` | string | 摄取 Job ID，经 `GET /ingestions/{job_id}` 轮询 |
| `status` | enum | 受理即 `RECEIVED` |
| `duplicate` | bool | 重复投递 `true`（亦返回 202） |

# GET /ingestions/{job_id}

查询摄取任务处理状态。无请求体。

## 响应体（HTTP 200）

| 字段 | 类型 | 含义与取值 |
|---|---|---|
| `status` | enum | `RECEIVED` / `PROCESSING` / `RETRY` / `COMPLETED` / `CANCELLED` / `DEAD_LETTER`（attempts 满 5 进死信） |
| `attempts` | int | 已尝试次数 |
| `last_error_code` | string | 最近失败码，无则 `null` |
| `available_at` | datetime | 下次可执行时间（退避中） |

# GET /customers/{customer_id}/memories

agent 在 key 客户范围内查看客户记忆摘要；grant 交叉校验 + 审计前置。

## 请求参数（query）

| 字段 | 类型 | 必填 | 含义与取值 |
|---|---|---|---|
| `limit` | int | 否 | 默认 20，最大 100 |
| `cursor` | string | 否 | 上一页返回的游标 |
| `memory_type` | enum | 否 | 按类型过滤，6 值同 `include_types`【新定义】 |

## 响应体（HTTP 200）【新定义】

| 字段 | 类型 | 含义与取值 |
|---|---|---|
| `items[].memory_id` | string | 记忆 ID |
| `items[].memory_type` / `fact_key` | enum / string | 类型与事实键 |
| `items[].summary` | string | 脱敏摘要，≤160 字符 |
| `items[].lifecycle_status` | enum | `ACTIVE` / `RESOLVED` / `CONFLICTED` / …（12-状态机） |
| `items[].confidence_label` | enum | 同检索响应 |
| `items[].valid_at` / `expires_at` | datetime | 生效 / 过期时间 |
| `next_cursor` | string | 下一页游标，无则 `null` |

# POST /memories/{memory_id}/feedback

记录错误/有用反馈。`Idempotency-Key` 必需；反馈不自动提升可信度。

## 请求体

| 字段 | 类型 | 必填 | 含义与取值 |
|---|---|---|---|
| `feedback_type` | enum | 是 | `INCORRECT` / `OUTDATED` / `IRRELEVANT` / `HELPFUL` / `PRIVACY` / `OTHER` |
| `reason_code` | string | 否 | 原因码（自由文本，枚举未集中定义） |
| `comment` | string | 否 | 补充说明，落库前脱敏（`comment_redacted`） |
| `correction` | object | `INCORRECT` 必填 | 修正内容，字段同 CandidateInput（`explicit_correction=true`），创建 correction 候选走决策引擎 |
| `request_id` | string | 否 | 关联检索请求，用于 usage 归因 |

## 响应体（HTTP 200）【新定义】

| 字段 | 类型 | 含义与取值 |
|---|---|---|
| `feedback_id` | string | 反馈记录 ID |
| `correction_candidate_id` | string | 产生的 correction 候选 ID，无则 `null` |

落库字段：`request_id/memory_id/feedback_type/reason_code/actor_type(CUSTOMER/AGENT/SYSTEM/REVIEWER)/actor_id/comment_redacted/created_at`。实际采用情况由 `memory_usage_event` 异步记录（`retrieved_memory_ids/used_memory_ids/rank_map/matched_views/answer_hash/model_version/used/degraded`，`purpose` 与检索枚举一致）。

# POST /memories/{memory_id}/corrections

提交修正建议，进入决策流程。`Idempotency-Key` 必需。

## 请求体【新定义】

字段同 CandidateInput（见 `/memories/candidates`），服务端固定 `explicit_correction=true` 并关联 `memory_id`；`memory_type/fact_key` 缺省继承原记忆。

## 响应体（HTTP 202）

同 `/memories/candidates` 决策结果。

# POST /deletion-requests

请求删除客户记忆；建屏障 + 审核任务（4-eyes）。`Idempotency-Key` 必需。

## 请求体

| 字段 | 类型 | 必填 | 含义与取值 |
|---|---|---|---|
| `request_source` | enum | 是 | 用户面仅 `USER`（其余 `COMPLIANCE`/`ADMIN`/`SYSTEM`/`CONSENT_WITHDRAWN`/`DELETE_REQUESTED` 为内部/管理面） |
| `legal_basis` | string | 否 | 法律依据（如 GDPR Art.17） |
| `scope` | object | 是 | 用户面仅 `{all: true}`；子集 `{memory_type:[...], fact_key:[...]}` 仅内部/管理面 |

`customer_id` 由 `X-Customer-Id` 注入，`requested_by` 取 agent 身份。

## 响应体（HTTP 202）【新定义】

| 字段 | 类型 | 含义与取值 |
|---|---|---|
| `request_id` | string | 删除请求 ID |
| `status` | enum | 受理即 `RECEIVED` |
| `barrier_generation` | int | 删除屏障代际 |

# GET /deletion-requests/{request_id}

查询删除执行状态与证明。无请求体。

## 响应体（HTTP 200）

| 字段 | 类型 | 含义与取值 |
|---|---|---|
| `status` | enum | `RECEIVED` → `APPROVED` → `IN_PROGRESS` → `VERIFYING` → `COMPLETED`；分支 `REJECTED` / `CANCELLED` |
| `barrier_status` | enum | `ACTIVE` / `COOLING_DOWN` / `COMPLETED` / `CANCELLED` |
| `counts` | object | 各表删除计数（`memory_deletion_item` 状态：`PENDING`/`DELETED`/`ANONYMIZED`/`SKIPPED`/`FAILED`/`VERIFIED`） |
| `proof` | object | `COMPLETED` 后返回，结构见 2.2 `/admin/deletion-requests/{id}/proof` |

| `status` | enum | 否 | `PENDING` / `IN_REVIEW` / `APPROVED` / `REJECTED` / `EXPIRED` / `CANCELLED`，默认 `PENDING` |

## 响应体（HTTP 200）

| 字段 | 类型 | 含义与取值 |
|---|---|---|
| `items[].review_id` | string | 审核任务 ID |
| `items[].task_type` | enum | `CANDIDATE` / `CONFLICT` / `DELETION` |

| `items[].priority` / `due_at` | int / datetime | 优先级与截止时间 |
| `items[].assigned_to` | string | 指派审核人 |
| `items[].suggested_action` | string | 建议动作 |
| `items[].decision_version` | int | 乐观锁版本，决策提交时必带 |

# POST /review-queue/{review_id}/decision

审核结论提交；批准即执行（与业务写入同事务）。`Idempotency-Key` 必需。

## 请求体

| 字段 | 类型 | 必填 | 含义与取值 |
|---|---|---|---|
| `decision` | enum | 是 | `APPROVE` / `REJECT` |
| `decision_version` | int | 是 | 乐观锁，与待审项当前版本一致，否则 409 |
| `reason_code` | string | 是 | 结论原因码（如 `CONFLICT_TIMEOUT_EXPIRED` / `REVIEW_NOT_ACTIONABLE`） |
| `note` | string | 否 | 说明，落库前脱敏（`resolution_note_redacted`） |
| `co_reviewer_id` | string | `HIGH` 必填 | 复核人；4-eyes：批准人 ≠ 提交人 |

## 响应体（HTTP 200）【新定义】

| 字段 | 类型 | 含义与取值 |
|---|---|---|
| `review_id` | string | 审核任务 ID |
| `status` | enum | `APPROVED` / `REJECTED` |
| `decision_version` | int | 递增后的版本 |
| `execution` | object | 批准即执行的结果（决策结果结构同 `/memories/candidates`），拒绝为 `null` |
